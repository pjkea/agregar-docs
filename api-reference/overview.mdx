Base URL:

```
https://monitor.agregartech.com/api/v1
```

This page lists the endpoints an integrating institution uses. The API exposes more than these — platform administration, rule authoring, ML operations and analytics are used by the Validar console, not by your integration — so they are omitted here deliberately. The full machine-readable surface is always at [`/openapi.json`](https://monitor.agregartech.com/openapi.json).

**Key**: `K` = API key (`X-API-Key`) · `T` = Bearer token · see [Authentication](/authentication).

---

## Send transactions

| Endpoint | Auth | Purpose |
|---|:---:|---|
| `POST /ingestion/transaction` | K T | Submit one transaction |
| `POST /ingestion/batch` | K T | Submit up to 1,000 (needs `source_system`) |
| `POST /ingestion/validate` | K T | Check a payload without storing it |
| `GET /ingestion/batch/{batch_id}/status` | K T | Progress of a batch |

See [Ingestion](/guides/ingestion).

## Read what happened

| Endpoint | Auth | Purpose |
|---|:---:|---|
| `GET /alerts` | K T | List alerts. Filters: `customer_id`, `priority`, `status`, `assigned_to`, `start_date`, `end_date` |
| `GET /alerts/{alert_id}` | K T | One alert, with the rules that fired |
| `GET /transactions` | T | List transactions |
| `GET /transactions/{transaction_id}` | T | One transaction, with its score breakdown |
| `GET /customers/{customer_id}/risk-profile` | T | Customer risk profile |
| `GET /customers/{customer_id}/transactions` | T | That customer's transactions |
| `GET /customers/{customer_id}/alerts` | T | That customer's alerts |

<Warning>
  The rows marked **T** reject an API key with `401 Could not validate credentials`. Use a Bearer token for those.
</Warning>

See [Alerts](/api-reference/alerts) and [Transactions](/api-reference/transactions).

## Work an alert

| Endpoint | Auth | Purpose |
|---|:---:|---|
| `PATCH /alerts/{alert_id}` | T | Update status or priority |
| `POST /alerts/{alert_id}/assign` | T | Assign to an analyst |
| `POST /alerts/{alert_id}/resolve` | T | Close it, with a reason |
| `POST /alerts/{alert_id}/escalate` | T | Escalate into a case |
| `POST /alerts/{alert_id}/notes` | T | Add a note |

## Conventions

- **Paging**: `page` (from 1) and `page_size` on every list endpoint. Responses carry `items` plus a total.
- **Dates**: ISO-8601 UTC, e.g. `2026-09-11T09:30:00Z`.
- **Money**: decimal, not minor units. `5000.00` means 5,000.00.
- **Errors**: see [Errors](/guides/errors) for every code and its fix.
